# Site pessoal / Aisthesis Lab

Estrutura inicial em HTML, CSS e JavaScript para publicação no GitHub Pages.

## Arquivos principais
- index.html
- projetos.html
- sobre.html
- cursos.html
- blog.html
- contato.html
- assets/css/style.css
- assets/js/main.js

## Antes de publicar
1. Substitua os textos provisórios.
2. Troque os links `#` pelos endereços reais.
3. Altere `seuemail@exemplo.com`.
4. Configure o formulário do Formspree e substitua `SEU_CODIGO`.
5. Adicione imagens em `assets/img/`.
6. Envie todos os arquivos para a raiz do repositório usado no GitHub Pages.
